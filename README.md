# Didula Weerasekara — Personal Website

A free, responsive static website designed for GitHub Pages.

## Publishing (no coding required)

1. Sign in to https://github.com/didulaweerasekara
2. Click **New repository**.
3. Name the repository **didulaweerasekara.github.io** (exactly).
4. Choose **Public** and click **Create repository**.
5. Choose **uploading an existing file** (or **Add file → Upload files**).
6. Upload `index.html`, `styles.css`, and `script.js` from this folder. They must be at the repository root, not inside a subfolder.
7. Click **Commit changes**.
8. In repository **Settings → Pages**, select **Deploy from a branch**, **main**, and **/(root)**, then save if not already configured.
9. Visit https://didulaweerasekara.github.io/ after GitHub finishes deploying. It may take several minutes.

## Editing

- `index.html`: all text, section headings, links and page structure.
- `styles.css`: fonts, colours, layout, mobile styles.
- `script.js`: mobile navigation and automatic footer year.

## Before making the site public

- Review the biographical text for accuracy.
- Supply a preferred public contact email or other contact method if you want direct enquiries.
- Add a real portrait when ready; the current hero uses original typographic art instead of a generic person's photograph.
- Add articles when available. The writing section is currently marked 'coming soon'.

This site does not require a domain purchase, paid hosting, build tools, or a backend. Google Fonts is loaded from Google's CDN; the site falls back to system fonts if unavailable.
